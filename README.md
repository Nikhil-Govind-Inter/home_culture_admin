# Home Culture Admin Dashboard

Vite + React 18 + TypeScript + shadcn/ui + Tailwind admin dashboard for the Home Culture CMS (`../server`).

## Setup
1. `cp .env.example .env` (points at the server on `http://localhost:5000`).
2. `npm install`
3. `npm run dev` (port 8080), `npm run build`, `npm run lint`

Sign in with the admin created by `npm run seed` in `../server`.
